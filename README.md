# ⚡️ PRIME RUSH - 素数判定ゲーム -

PHPとJavaScript（Fetch API）を組み合わせた、ブラウザでサクサク遊べるスタイリッシュな素数判定ゲームです。
画面遷移（リロード）のない、なめらかな操作感と近未来的なダークモード風のUIが特徴です。

## 🎮 ゲーム概要

次々に表示されるランダムな数字（2〜100）が、**「素数（Prime）」**か**「合成数（Not Prime / 素数以外）」**かを瞬時に見極めてボタンを押すゲームです。全5問の正解数に応じて、最終的なランクが評価されます。

- **スマートな間違え探しのヒント**: 合成数を間違えて「素数」と答えてしまった場合、その数が「何の数で割り切れるのか（因数）」を教えてくれる親切設計です。
- **軽量な単一ファイル構成**: `index.php` 1ファイルだけでフロントエンドからバックエンド処理まで完結しています。

## 🚀 動作環境

- **PHP**: 7.4 以上（8.x 推奨）
- **ブラウザ**: Google Chrome, Microsoft Edge, Safari などのモダンブラウザ
